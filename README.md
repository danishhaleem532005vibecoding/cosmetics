# ✨ Lumière — Cosmetics & Beauty E-Commerce Website

Welcome to **Lumière**, a modern and elegant cosmetics e-commerce website created to provide a premium online shopping experience for beauty and skincare products.

## 🌸 About Lumière

Lumière is a frontend cosmetics store designed with a luxury-inspired visual style. The website presents beauty products in a clean, attractive, and responsive interface, making it easy for customers to explore products and discover their favorite beauty essentials.

## 🛍️ Features

* ✨ Modern and premium cosmetics design
* 💄 Makeup product showcase
* 🧴 Skincare & beauty products
* 🛒 E-commerce-style shopping experience
* 📱 Fully responsive design
* 🎨 Elegant UI/UX
* ⚡ Smooth animations and interactions
* 🔎 Product-focused layout
* 🌐 Mobile, tablet, and desktop support
* 💎 Luxury-inspired branding

## 📂 Website Sections

* Home
* Shop / Products
* Makeup
* Skincare
* Beauty Essentials
* About
* Contact

## 🛠️ Technologies

This project can be built and customized using:

* HTML5
* CSS3
* JavaScript
* Responsive Web Design
* Modern UI/UX principles

## 🎯 Project Purpose

The purpose of Lumière is to demonstrate a professional cosmetics e-commerce website concept that can be customized for beauty brands, cosmetic stores, skincare businesses, and online retailers.
